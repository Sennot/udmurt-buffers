\# UDMURT Buffers



Fine-grained companion for \*\*Input Buffer\*\* (`lyophi.buffermod`), built for \*\*Geode v5.7.1\*\*.



\## Features



\- Per-mode toggles: Cube, Ship, Ball, UFO, Wave, Robot, Spider, Swing.

\- Per-click-type toggles: Landing, Orb, Min Hold, Min Gap, Grid.

\- Custom delay windows 0–16 (0 = use Input Buffer default).

\- Unit selector: frames (configurable FPS, default 60) or ticks (1/240 s).

\- Per-mode override windows for Ship, UFO, Wave, Swing.

\- Custom black/red/white themed UI with per-toggle switches.



\## Compatibility



\- GD 2.2081 (Windows)

\- Geode v5.7.1+

\- Optional dependency on `lyophi.buffermod`.
